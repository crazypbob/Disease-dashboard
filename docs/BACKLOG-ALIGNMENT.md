## 2. 지도: 데모 유지 vs 실DB 연동 (P5 일부)

| 항목 | 합의 |
|------|------|
| 단기 | 지도의 **주황 가상 양성**·**ASF 가상 30점·동심원·우측 패널**은 **시연·명세 대응용 데모로 유지**. |
| 실DB 연동 | `test_records`(또는 동등 집계) 기반 **실질 양성·질병 필터**는 **별도 작업**: 집계 API 스코프·관할 규칙을 설계한 뒤 구현([TODO.md](TODO.md) P5 첫 항목). |
| ASF 실데이터 | 공공 데이터 연계 여부는 **실DB 연동 차수**에서 재검토(데모와 병행 vs 대체). |
| UI | 실데이터 도입 시 **「데모 / 실데이터」 토글** 검토를 권장(구현 시 [FarmMapPanel](../components/FarmMapPanel.tsx) 일대). |

## 3. 지도 RBAC: 서버 `MATRIX_*`와의 관계 (P5 일부)

| 항목 | 합의 |
|------|------|
| 단기 | 지도 탭 역할(정부·수의사·공수의·농장주)은 **클라이언트 토글 데모**로 유지 — 시연·개발 편의. |
| 중기 | 로그인 세션의 `matrixScope`·`MATRIX_*_EMAILS` 철학과 **지도 스코프를 맞추는 작업**을 별도 이슈로 둠([TODO.md](TODO.md) P5 RBAC 항목). |
