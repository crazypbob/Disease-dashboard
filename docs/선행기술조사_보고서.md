## 결론 요약

**"복수 농장 × 질병 × 날짜 축 매트릭스 시각화 + RBAC 기반 수의진단 대시보드"를 통합한 특허는 국내외에서 발견되지 않음.**

- 국내 특허: 영상·센서 기반 가축 모니터링, GIS 지도 기반 방역 특허는 다수 존재하나, **실험실 검사결과(PCR/ELISA)를 매트릭스 형태로 시각화하고 역할별로 접근 범위를 달리하는 구조의 특허는 없음**
- 해외 특허: AI·영상·IoT 기반 질병 감지 특허 중심이며, 수의진단 결과 데이터의 매트릭스 시각화 특허 없음
- 비특허 선행기술: Ontario 대시보드(캐나다, 2023년 논문) — 진단결과 시각화 개념 유사하나, **특허 아님, RBAC·매트릭스 구조 없음**

## 4. KAHIS(국가가축방역통합시스템) 관련

- 공개 특허 데이터베이스에서 **KAHIS 명의 소프트웨어 특허 미발견**
- 정부 시스템은 특허 대신 소프트웨어 저작권 등록 경향
- KAHIS는 방역기관 내부 행정 시스템으로, 농장주/수의사 역할별 외부 공개 서비스가 아님
- **KAHIS와 본 발명의 차이**: 본 발명은 ① 민간 진단기관 이메일 PDF를 자동 수집·파싱, ② 외부 사용자(농장주, 수의사) 대상 RBAC 제공, ③ 매트릭스 시각화가 핵심

## 6. 특허 출원 전략 권고

### 핵심 청구항 (신규성 강함, 최우선 확보)
1. **청구항 1** (매트릭스 시각화) — 가장 강력한 핵심 청구항
2. **청구항 4** (RBAC 구조) — 구조 특허로 활용 가능
3. **청구항 2** (PDF 원본 연결) — 간단하지만 기존 특허 없음

### 보완이 필요한 청구항
- **청구항 6** (지도 + 질병 레이어): GIS 관련 선행기술(KR20150135656A)이 있으므로, **매트릭스 뷰와 지도 뷰의 연동 구조**를 청구항에 명시하여 차별화 필요
- **청구항 8** (항체가 시계열): 시계열 그래프 자체보다는 **매트릭스 셀에서 드릴다운하는 구조** 또는 **다기관 데이터 통합 추이**를 강조하여 차별화 필요

### Ontario 논문 대응
- 2023년 발표이므로 출원일 이전 공지기술로 인정될 수 있음
- 대응 전략: 청구항에 "RBAC 기반 접근 제어", "PDF 보고서 OCR 자동 파싱 연동", "셀 클릭 → 원본 문서 열람" 등 Ontario 대시보드가 가지지 않은 구성을 명시적으로 포함

## 7. KIPRIS 직접 검색 권고

   - `(질병 AND 매트릭스 AND 대시보드)`

   - `(농장 AND 역할 AND 접근제어)`

   - `A01K 29/00` (가축 상태 감시)
