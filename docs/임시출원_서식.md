## 3. 임시출원 핵심 내용 요약 (출원서 내 "발명의 내용" 란)

> 임시출원서에는 아래 요약문을 붙여넣어도 됩니다.

### 발명의 요약

본 발명은 복수의 양돈 농장에서 발생하는 질병 검사결과(PRRS, PED, SIV, PCV2, MH, APP, 세균 배양, 유전자 검사 등)를 **농장(행) × 질병/검사타입(열) × 날짜(열그룹)** 의 3축 매트릭스 형태로 시각화하고, 사용자 역할(정부기관, 돼지진료 수의사, 공수의, 농장주)에 따라 접근 가능한 농장 범위를 자동으로 제한하는 웹 기반 방역 정보 플랫폼이다.

### 주요 특징

1. **3축 매트릭스 시각화**: 항원(Ag)·항체(Ab) 검사결과를 동일 질병의 서브컬럼으로 나란히 배치하여 방역 판단에 필요한 두 검사 타입을 단일 화면에서 비교 가능하게 한다. 각 셀에서 원본 검사 문서(PDF)로의 직접 접근을 지원한다.

2. **역할 기반 접근 제어(RBAC)**: 정부기관(중앙·지자체), 수의사(계약 농장), 공수의(관할 지역), 농장주(본인 농장+인근 익명 현황)의 6종 데이터 접근 범위를 서버사이드에서 제어한다.

3. **농장 익명화 + 반경 공개**: 농장 고유 식별코드 기반으로 개인정보를 비노출하면서, 특정 질병 선택 시 반경(1~10km) 내 익명 농장 발생 현황을 제공한다.

4. **검사결과 자동 수집 파이프라인**: 검사기관으로부터 전자적 방법(이메일, API 연계, 파일 포털 등)으로 수신된 비정형 PDF 결과지를 파싱 모듈(OCR·AI·규칙 기반 등)을 통해 구조화하여 중앙 데이터베이스에 자동 반영한다.

5. **지도 시각화**: 전국 또는 권한 범위 내 농장을 GPS 좌표 기반 지도에 표시하고, 질병 필터 선택 시 발생 농장을 레이어 형태로 강조한다.

## 4. 청구항 요약 (임시출원용 간략 버전)

> 임시출원에는 청구항이 반드시 필요하지 않으나, 기재하면 출원 내용 명확화에 도움이 됩니다.
> 정식 청구항은 `docs/특허명세서_초안.md` 청구항 1~10을 참조하세요.

**청구항 1 (독립항 — 방법):**
복수의 양돈 농장에 대한 질병 검사결과를, 농장을 행으로 하고 검사일·질병·검사타입(항원/항체)을 열로 하는 2차원 매트릭스로 표시하는 단계; 상기 매트릭스의 각 셀을 선택 시 해당 검사결과의 원본 문서로 접근하는 단계; 및 사용자의 역할에 따라 상기 매트릭스에 표시되는 농장의 범위를 서버에서 제한하는 단계;를 포함하는 축산 방역 정보 시각화 방법.

**청구항 2 (독립항 — 시스템):**
복수의 양돈 농장 질병 검사결과 데이터를 저장하는 데이터베이스; 상기 데이터베이스로부터 사용자 역할에 따라 허용된 농장 집합의 데이터만을 조회하여 반환하는 API 서버; 및 상기 API 서버로부터 수신한 데이터를 농장(행) × 날짜·질병·검사타입(열)의 매트릭스로 렌더링하고, 각 셀에서 원본 검사 문서로의 링크를 제공하는 웹 클라이언트;를 포함하는 축산 방역 정보 시각화 시스템.

## 5. KIPRIS 특허로 제출 절차

### 5-1. 사전 준비

1. **KIPRIS 회원가입 및 특허고객번호 발급**
   → [https://www.patent.go.kr](https://www.patent.go.kr) 회원가입 → 특허고객번호 신청 (공인인증서/간편인증 필요)

2. **공인인증서 또는 금융인증서 준비**
   → 전자출원 시 전자서명 필요

3. **출원료 준비**
   → 임시출원 수수료: **46,000원** (2024년 기준, 개인 출원인 감면 가능)
   → 단독 발명자·개인 출원 시 **소규모 출원인(중소기업·개인) 감면** 신청 가능

### 5-2. 전자출원 단계

1. [KIPRIS 특허로](https://www.patent.go.kr) 로그인
2. **출원** 메뉴 → **특허·실용신안 출원** → **임시출원서 작성**
3. 출원인·발명자 정보 입력 (1항 참조)
4. 발명의 명칭 입력 (1-3항 참조)
5. **첨부 파일 업로드**:
   - 임시 명세서 (PDF/HWP): `특허명세서_초안.md` 변환본
   - 도면 파일들 (JPG/PDF): `patent-drawings/` 폴더의 도면 파일들
6. 전자서명 후 제출
7. 출원번호·출원일 확인 → **출원일을 반드시 기록**

### 5-3. 제출 후 확인 사항

- [ ] 출원번호(예: 10-2026-XXXXXXX) 및 출원일 기록
- [ ] 출원 영수증 저장 (수수료 납부 증빙)
- [ ] 정식출원 기한 캘린더 등록: **임시출원일 + 12개월** 이내
- [ ] 특허사무소 연락 일정 잡기 (정식출원 전 변리사 검토 권장)
